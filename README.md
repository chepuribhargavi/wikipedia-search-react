# Wikipedia Search Application

A React-based Wikipedia Search Application that allows users to search Wikipedia articles using a REST API.

## Features

- Search Wikipedia articles
- Display article title, URL, and description
- Loading spinner while fetching data
- Responsive UI using Bootstrap
- Built with React functional components and Hooks

## Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Bootstrap
- REST API
- Vite

## Installation

```bash
npm install
npm run dev
```
